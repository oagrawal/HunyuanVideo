To Run VBench eval:

- tell cursor to create script to eval visual quality of videos in the folder
- evaluate_videos.py evaluates video quality
- display_results.py displays the results in an easy to understand manner


How to restore docker container for hunyuanvideo_backup_image
- docker load -i /nfs/oagrawal/hunyuanvideo_backup.tar
- After loading, you can update your hv-create alias to use your backed-up image name (hunyuanvideo_backup_image) instead of the original hunyuanvideo image name at the end of the command.
(see top of this file for how to create the alias)

make sure to pip install from requirements.txt after you restore the docker container


##########################################################################################################################################
ADAPTIVE VS FIXED THRESHOLD EXPERIMENT
##########################################################################################################################################

Use --teacache-mode with: none, fixed, or adaptive
Use same --seed across all runs for fair comparison.

# Baseline (no caching)
python3 teacache_sample_video.py \
    --video-size 544 960 --video-length 129 --infer-steps 50 \
    --prompt "Two anthropomorphic cats in comfy boxing gear and bright gloves fight intensely on a spotlighted stage." \
    --flow-reverse --use-cpu-offload --save-path ./teacache_results \
    --teacache-mode none --seed 12345

# Fixed thresholds (0.10, 0.20, 0.30)
python3 teacache_sample_video.py \
    --video-size 544 960 --video-length 129 --infer-steps 50 \
    --prompt "Two anthropomorphic cats in comfy boxing gear and bright gloves fight intensely on a spotlighted stage." \
    --flow-reverse --use-cpu-offload --save-path ./teacache_results \
    --teacache-mode fixed --fixed-thresh 0.10 --seed 12345

python3 teacache_sample_video.py \
    --video-size 544 960 --video-length 129 --infer-steps 50 \
    --prompt "Two anthropomorphic cats in comfy boxing gear and bright gloves fight intensely on a spotlighted stage." \
    --flow-reverse --use-cpu-offload --save-path ./teacache_results \
    --teacache-mode fixed --fixed-thresh 0.20 --seed 12345

python3 teacache_sample_video.py \
    --video-size 544 960 --video-length 129 --infer-steps 50 \
    --prompt "Two anthropomorphic cats in comfy boxing gear and bright gloves fight intensely on a spotlighted stage." \
    --flow-reverse --use-cpu-offload --save-path ./teacache_results \
    --teacache-mode fixed --fixed-thresh 0.30 --seed 12345

# Adaptive thresholds (low for first 10 + last 5 steps, high for middle)
python3 teacache_sample_video.py \
    --video-size 544 960 --video-length 129 --infer-steps 50 \
    --prompt "Two anthropomorphic cats in comfy boxing gear and bright gloves fight intensely on a spotlighted stage." \
    --flow-reverse --use-cpu-offload --save-path ./teacache_results \
    --teacache-mode adaptive --thresh-low 0.05 --thresh-high 0.20 --seed 12345

python3 teacache_sample_video.py \
    --video-size 544 960 --video-length 129 --infer-steps 50 \
    --prompt "Two anthropomorphic cats in comfy boxing gear and bright gloves fight intensely on a spotlighted stage." \
    --flow-reverse --use-cpu-offload --save-path ./teacache_results \
    --teacache-mode adaptive --thresh-low 0.05 --thresh-high 0.30 --seed 12345
